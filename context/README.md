# 大连理工项目上下文

> **文档状态**：候选项目上下文，供项目成员和表达 Agent 使用；不是项目正式裁决、技术验收或发布授权文件。
> **整理日期**：2026-10-28

`context/` 是大工项目对外表达资产仓库的结构化理解入口。它保存经过整理的项目摘要、对象关系、阶段判断、来源定位和表达边界，帮助成员和 Agent 在制作任务、汇报材料和作品前建立共同语境。

本目录不替代项目专业事实源，也不复制源码、原始实验数据、原始聊天或受限附件。技术事实、任务责任和授权状态需要回到登记的来源及相应真人确认记录核对。

## 来源主位

- `houzai` 是项目专业事实、任务、研发材料和会议材料的主要来源。
- 本 public 资产仓库承载脱敏上下文、表达任务、作品、来源关联和评审记录。
- `vendor/suanhai-team-external-expression-infrastructure/` 只提供固定版本的通用基础设施；实际可用能力以当前 gitlink 对应的 Manifest 为准，不承载大工项目事实，不能根据目录存在或历史测试推断能力状态。
- SuanhaiOS 可以提供任务环境和团队协作支持，但不是大工项目技术事实或发布授权的主数据库。

## 状态标记

- **已确认**：有正式记录或责任主体明确确认，可在限定范围内作为事实前提使用。
- **有证据但未验收**：已有报告、日志、测试或会议材料，尚未完成正式审查或验收。
- **草稿或计划**：候选方案、未来安排或尚未执行的工作。
- **待核对**：来源、责任、数据、适用条件或授权仍存在不确定性。

一个文件可以存在，但其内容仍可能是草稿、未验收或待核对状态。文件存在、版本提交、检查通过或作品生成，都不能自动推出技术结论、任务关闭或发布授权。

## 维护原则

1. 结构化理解文档只保存摘要和关系，不复制私有专业资料。
2. 每项重要主张都要能够定位到来源、日期、适用条件和事实状态。
3. 事实、判断、候选机制、计划、验收和授权分开表达。
4. Houzai 出现新材料或来源冲突时，先更新来源登记和当前状态，再修订作品。
5. public 作品发布前，必须单独核对受众、用途、内容范围和真人授权。
