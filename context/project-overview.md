# 项目概览

> **文档状态**：候选项目上下文
> **整理日期**：2026-10-28
> **主要依据**：`houzai` 项目说明、项目上下文索引、三条工作主线材料和 2026-10-23 双周材料

## 1. 项目身份

项目正式名称为：**大连理工结构力学计算异构并行项目**。

它是一项外部合作研发项目，围绕既有结构有限元 CPU/MPI 求解体系，组织工程条件准备、性能问题验证和异构并行架构研究。项目结果用于判断后续接口衔接、工程集成、资源投入和范围调整的可行性。

## 2. 项目为什么存在

现有结构力学计算流程已经具备一定的模型处理、分区、求解和结果恢复能力，但在复杂约束、负载均衡、迭代法稳定性、数据准备和 CPU/GPU 协同方面仍有需要验证的问题。单次测试或单个算法结果不足以支撑软件重构决策，因此项目需要把上游结构、区域分解与求解器、异构执行路径放到可复核的算例和统一口径下共同观察。

## 3. 项目要解决的问题

项目当前集中回答以下问题：

- 工程环境、源码、依赖、算力和测试口径能否稳定复现；
- 网格分区、约束关系和任务划分如何影响负载、接口、通信和求解资源；
- PETSc、BDDC、直接法和其他求解路径在代表性算例上如何表现，哪些问题仍不收敛或出现异常；
- TensorFem 和多后端异构路线能否在明确的数据边界、正确性口径和资源条件下继续工程化；
- 三条工作主线能否共享算例、环境、证据和验收口径，形成可供双方判断的阶段材料。

## 4. 项目目标

当前项目目标是形成**可复核的阶段证据和可评估的工程路线**，支撑双方判断后续接口衔接、软件重构、算力配置和研发范围。目标包含：

1. 建立可复现的工程和性能基线；
2. 识别分区、约束、求解器、通信和数据路径中的实际瓶颈；
3. 在限定算例和环境下验证多后端、GPU、MPI 及 `matrix-free` 路径的正确性与可行性；
4. 形成带有证据、限制、风险和协作条件的阶段性表达材料。

这些目标不等同于已经承诺完成完整生产级重构、所有单元类型覆盖或所有规模下的统一加速。

## 5. 工作范围

当前范围由三条并行工作主线组成：

| 主线 | 工作范围 |
| --- | --- |
| 工程预备 | 访问、源码、构建、依赖、配置、算力、算例和复现条件 |
| 性能专项 | 性能基线、热点、分区、约束、预条件子、区域分解、求解器、数据路径和 `matrix-free` 验证 |
| 架构设计 | SGSim 现状、多后端、TensorFem、MPI、CPU/GPU 路径、接口边界和迁移条件 |

三条主线可以同时推进。工程预备提供条件，性能专项暴露问题，架构设计组织解决路径；它们通过共同算例、环境、证据和验收口径相互关联，不构成固定先后流程。

## 6. 明确不包含的内容

基于当前来源，以下内容不应被写成项目已经承诺或已经完成的范围：

- 面向全部算例的通用加速结论；
- 已完成生产级多节点多 GPU 替代方案；
- BDDC、分区或 TensorFem 的正式工程验收；
- 将 MFEM 等参考实现直接等同为 SGSim 的既定目标架构；
- GUI、几何建模或网格生成作为当前主要交付；
- 仅凭文件存在、代码提交或测试通过推断任务关闭、技术结论成立或内容可公开。

## 7. 当前阶段判断

截至 2026-10-23，项目处于**工程可行性与跨方向验证阶段**。网格分区、区域分解与 BDDC、TensorFem 异构计算均已有阶段性材料，但仍需统一算例、构建版本、硬件、进程/线程、正确性、残差和计时口径。多 GPU、多节点、复杂约束和 `matrix-free` 端到端路径尚未形成完整结论。

这是有证据但未验收的阶段判断，不能替代项目负责人、技术负责人或合作方对正式阶段和交付范围的确认。
