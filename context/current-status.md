# 当前状态快照

> **文档状态**：候选状态快照，待项目负责人核对

## 1. 总体判断

项目已从单点技术探索进入**工程可行性和跨方向验证阶段**。截至 2026-10-23，网格分区与任务划分、区域分解与 BDDC、TensorFem 异构计算三组材料已经形成阶段性可复核证据；下一步重点是把三条路线放到同一代表性算例、统一构建环境、统一残差和统一计时口径下衔接。

该判断是“有证据但未验收”的阶段性判断，不等同于项目整体完成或正式工程交付。

## 2. 三组阶段证据

### 网格分区与任务划分

- 已将 SPC、MPC、RBE2/RBE3 等约束纳入独立自由度和分区访问关系分析；
- 50w、100w、RBE 和混合模型中出现了有效、无明显改善和失败的对照结果；
- 现有收益仍需结合分区生成、装配、约束、通信、分解和结果恢复，不能只看 DOF 比或单一阶段时间；
- 当前结论：分区策略应跟随实际瓶颈，并同时考虑独立自由度、单元类型、接口和连通性。

### 区域分解与 BDDC

- 已在约 1136 万阶大规模圆筒模型上形成直接法、几何分区和 BDDC 对照；
- 当前材料记录了 BDDC 与直接法在特定配置下的完整时间、残差和资源对照，但两组精度和配置不同，不能直接推出普遍优劣；
- Pshear 的两种 128 子域组织在 BDDC 粗层构造阶段出现零主元，未进入 CG，原因仍需保存失败块数值、索引和约束关系后核对；
- 当前优先级为收敛稳定性、内存占用、计算效率，依次处理。

### TensorFem 异构计算

- 已在单机 8 卡 NVIDIA A10 环境中对 CPU、GPU、多进程和分阶段路径进行对照；
- 材料显示 GPU 求解端已经形成阶段性验证闭环，当前主要瓶颈转向数据准备、格式转换、主机—设备传输、通信和同步；
- 现有证据未覆盖多 GPU、多节点、复杂约束和 `matrix-free` 端到端路径，不能表述为生产替代或规模扩展结论。

## 3. 当前优先动作

1. 统一代表性算例、构建版本、硬件、进程/线程、正确性、残差和计时口径；
2. 复现并定位 Pshear 零主元、混合模型不收敛和异常负载问题；
3. 确认 BDDC 正式接入 `FEMSolve` 所需的子域数据、局部—全局映射、约束处理结果和局部分解库；
4. 明确 TensorFem 与 `DBManager` 的数据边界，并继续验证 GPU 通信、数据流转和 `matrix-free` 范围；
5. 在固定口径下准备后续异构框架和研发规划讨论材料。
