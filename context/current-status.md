## 3. 已有证据与表达限制

### 网格分区与任务划分

已登记材料将 SPC、MPC、RBE2/RBE3 等约束纳入独立自由度和分区访问关系分析，并在 50 万、100 万、RBE 和混合模型中记录了有效、无明显改善和失败的对照。当前可以支持“分区目标需要结合独立自由度、单元类型、接口和连通性”的阶段判断；分区生成、装配、约束、通信、分解和结果恢复尚未全部纳入统一端到端口径。

**来源状态**：有证据但未验收；来源标识为 `houzai.external-report-2026-10-23`、`houzai.grid-attachment-2026-10-23`。

### 区域分解与 BDDC

已登记材料包含大规模模型的直接法、几何分区和 BDDC 对照，以及多点约束、混合模型、二级子域和零主元记录。当前可以支持继续定位求解稳定性、局部子域、粗层和内存问题；不能据此推出 BDDC 对所有算例具有统一优势或已经完成正式接入。

**来源状态**：有证据但未验收；来源标识为 `houzai.external-report-2026-10-23`、`houzai.solver-attachment-2026-10-23`。

### TensorFem 异构计算

已登记材料包含单机多卡环境中的 CPU、GPU、多进程和分阶段对照，指出数据准备、格式转换、主机与设备之间的数据传输、通信和同步仍是重要分析对象。当前可以支持继续开展架构和性能验证；不能把现有结果写成生产替代、多节点扩展或所有算例的通用加速结论。

**来源状态**：有证据但未验收；来源标识为 `houzai.external-report-2026-10-23`、`houzai.tensorfem-attachment-2026-10-23`。

## 4. 当前主要动作

1. 统一代表性算例、构建版本、硬件、进程/线程、正确性、残差和计时口径。
2. 复现并定位零主元、混合模型不收敛和异常负载问题。
3. 确认 BDDC 接入 `FEMSolve` 所需的子域数据、局部—全局映射、约束处理结果和局部分解依赖。
4. 明确 TensorFem 与 `DBManager` 的数据边界，继续验证 GPU 通信、数据流转和限定范围的 `matrix-free` 路径。
5. 为下一次架构讨论整理已验证证据、候选方案、风险、协作条件和决策点。

这些是当前登记的工作方向，不等于所有任务已经创建、责任人已经确认或外部承诺已经变更。
