# 项目概览

## 1. 项目身份

项目正式名称为：**大连理工结构力学计算异构并行项目**。

项目材料位于 Suanhai 团队的 Houzai 项目仓库中。Houzai 的长期定位是面向建成环境的结构、构造、设备和附属系统相互作用的 CAX 实验性平台；大连理工项目是其中面向结构力学计算和异构并行能力建设的一项外部合作项目。

## 2. 当前问题与目标

当前项目围绕既有结构有限元 CPU/MPI 求解体系，开展以下工作：

- 建立可复现的工程环境、源码获取、依赖和计算资源基线；
- 分析性能瓶颈，验证分区、预条件子、求解器、Matrix-free 和并行配置的适用性；
- 研究多后端、MPI 和 CPU/GPU 异构并行架构；
- 形成可复核的阶段证据，为后续接口衔接、工程集成和范围判断提供依据。

项目的目标不是单独展示某一个算法或某一次加速结果，而是逐步判断：上游网格与约束结构、区域分解与求解器、异构执行路径能否在统一算例和统一验收口径下衔接起来。

## 3. 当前范围

当前结构化范围包括：

1. 工程预备：账号、访问、源码、构建、依赖、配置、算力和复现条件；
2. 性能专项：性能基线、热点、并行测试、预条件子、求解器、单元计算、数据访问和 Matrix-free；
3. 架构设计：SGSim 现状、多后端、MPI、异构并行、接口边界和迁移条件。

## 4. 当前不应作出的承诺

基于当前源材料，不能直接宣称：

- 已经形成适用于所有算例的通用加速结论；
- 已经完成生产级多节点多 GPU 方案或替代现有求解体系；
- BDDC、分区或 TensorFem 已完成正式工程验收；
- MFEM 调研已经等同于 SGSim 的目标架构；
- 某份报告、目录或提交存在就代表项目任务已关闭。

项目启动材料还明确：当前不以 GUI、几何建模或网格生成作为本项目的主要交付范围，也不把多节点多卡生产化改造写成已承诺交付。

## 5. 上下文使用原则

对外表达应优先从本项目已经允许引用的阶段报告、长期项目资产和明确确认记录中取材。专业研发代码、实验原始数据和合作方受限材料仍以其原仓库或受控位置为主位，本仓库只保存必要的摘要、引用和表达结果。
