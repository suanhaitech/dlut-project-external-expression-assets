## 独立 Agent 行为验证

测试者在隔离 clone 中启动不继承父会话聊天的独立子代理，先让制作代理从根规则发现能力，再向它提供预设合成用户输入；换会话恢复使用另一个不继承旧聊天的子代理。这是本会话中的 Agent 行为测试，不是 DSH 和 Codex 两种客户端的新机实测，也不能证明任意 Agent 都会遵守协议。

任务号：`EXPR-20261028-6460cf27`；始终保持 `mode: test`。作品只讨论“如何开始一次项目汇报任务”，来源限公开的根 README 和 AGENTS，不使用大工项目技术事实。

| 阶段 | 已观察到的结果 |
| --- | --- |
| 登记和澄清 | 制作代理自行读取规则及 Manifest，创建未对齐草案并提出三个方向性问题；未提前制作或伪造用户确认 |
| 对齐和首稿 | 收到明确标为合成测试的输入后补全 brief、记录原话并 align/start，生成 v001，停在 review，记录版本为 7 |
| 局部反馈 | 收到“下一步提前、减少重复说明，其他目标不变”后直接修订，无重复确认相同目标；第 2 轮生成独立 v002，保留 v001 |
| 检查和暂停 | v002 的下一步已前置，要点由 29 条减为 21 条；两版各三个本地链接可定位，validate 与 diff 检查通过。按指示暂停，记录版本为 10，resume_status 为 review，保存恢复核查事项 |
| 新会话只读恢复 | 仅提供任务号和只读恢复请求。新代理准确复述目标、已确认决定、版本、反馈、未确认事项和下一步；核对两版产出、来源和 submodule。任务仍为 paused / 第 2 轮 / version 10，前后四个任务及作品文件的 SHA-256 完全一致 |
| 恢复和本轮完成 | 测试者阅读实际 v002 后，提供明确标为合成测试的恢复与确认输入；代理先 resume 到 review / version 11，复核产出后 complete 到 completed / version 12，保留两版文件及用户原话。完成说明明确不构成专业验收或发布授权，并给出按编号续作方法 |
| 完成后范围变化重开 | 模拟用户要求受众改为首次加入团队的成员；代理核对旧完成记录，以 scope reopen 开启第 3 轮，进入 clarifying，再更新待对齐草案。第 2 轮 complete、已确认 v002 和两版文件摘要均保留；未制作 v003，未把旧确认当作新目标的确认 |

## 限制与后续验收

- 工具记录用户原话，不能验证发言者身份或授予发布许可。
- 任务状态工具不是后台Agent执行器、权限系统或沙箱。
- 首版评审摘要只绑定单个文件，含资源的网页还需要后续工程能力检查依赖资源；哈希能检测改写，不能自动备份或锁定文件。
- 跨设备恢复还要求任务与产出已经按用户授权同步；任务号本身不会同步文件。
- 真实项目任务、HTML制作、视觉质量和对外发布仍需分别验收。
