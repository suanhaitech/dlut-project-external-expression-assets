# 评审与确认记录

`reviews/` 保存作品和任务的评审意见、修订记录、待解决问题、责任收口和真人确认。

工程检查、内容评审、专业判断和对外发布授权应分开记录。评审文件存在不等于所有意见已经解决，也不等于作品已经获得发布许可；记录应注明状态、责任人和适用版本。
